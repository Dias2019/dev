# File Server
:wave: Hi there, welcome to another Java project!

This is originally taken from Hyperskill Academy's Java Developer certification [[link](https://hyperskill.org/projects/52?track=17)].  
Although the underline concept is a basic system design principle, we rarely get a chance to build it ourselves as it's usually handled via frameworks like Spring. But I believe that this project provides an opportunity to work on Server communication via Java Sockets and processing of multiple clients via Concurrency.

Project covers topics such as Socket communication, ReentrantLocks and multiple techniques to avoid race condition or data race.
